# ESP32-Arduino-Communication-System

An embedded systems project demonstrating communication between an **ESP32** and **Arduino Uno** using **UART** and **I2C**, along with **I2C-based LCD interfacing**.

## Overview

The project explores communication between multiple embedded devices using two commonly used communication protocols:

- **UART** for serial communication between ESP32 and Arduino Uno
- **I2C** for communication between ESP32 and Arduino Uno
- **I2C LCD** interfacing for displaying data

The project was developed to understand microcontroller communication, peripheral interfacing, and hardware-software interaction.

## Hardware Used

- ESP32
- Arduino Uno
- 16x2 LCD
- Jumper wires
- Breadboard

## Technologies Used

- C / Embedded C
- Arduino IDE
- UART
- I2C
- ESP32
- Arduino Uno
